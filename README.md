One letter for your day: **Q** — for *queasy*. A stomach-turning day, green around the gills: vivid, funny, and true. The field is drowned in Z (zero sleep), K (knackered), D (doomscrolled) and U (unhinged); Q stands apart, and queasy is Q's only possible initial.

## Run it

```sh
node main.ts
```

It writes exactly one character, `Q`, to `/output/entry.txt` — nothing else.
